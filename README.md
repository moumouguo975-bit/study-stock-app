# study-stock-app
# 📱 学财助手 Pro (Study & Finance Hub)

一款基于 **Capacitor 6 + Android 原生插件 + GitHub Actions 零服务器自动化** 构建的个人全能学习与生活助手 Android App。

无需本地安装 Android Studio，全程在 GitHub 云端自动编译打包 `.apk` 并每日定时更新全球股市与财经新闻数据。

---

## ✨ 核心功能一览

### 1. 🌤️ 多地区时钟、互动天气与智能建议
- **自动对齐设备位置与时区**：优先读取设备定位，兜底 IP 自动定位，精准同步当地时钟。
- **多地区管理**：支持手动添加/切换/删除全球多个城市（切换城市时自动同步当地时区时钟与天气）。
- **可滑动互动预报**：支持左右滑动查看 **未来 24 小时逐时天气时报** 与 **未来 7 天天气预报**，点击任意小时或日期即生成对应的穿衣、带伞、出行建议。
- **融合学习建议**：在本地城市视图下，自动结合当日课表与近期考试倒计时给出复习与作息提醒。

### 2. 📅 智能课表、考试日程与系统级闹钟
- **智能 OCR & 文档识课表**：内置 **Google ML Kit 离线中英文 OCR** 与 **Word (`.docx`) / Excel (`.xlsx`) / PPT (`.pptx`) / PDF / TXT** 文档解析，选图或选文档即可一键提取课程与日程。
- **多样提醒方式（关掉 App 依然有效）**：
  - 📱 **同步手机系统闹钟**（写入设备自带时钟，支持每周重复，锁屏/杀后台永不漏响）
  - 📅 **同步手机系统日历**（写入设备原生系统日历，支持循环规则）
  - ⏰ **App 15 秒连续响铃闹钟**（内置真实响铃音频与全屏响铃关闭界面）
  - 📳 震动横幅 / 🔔 普通通知

### 3. 📁 图文与多格式资料库
- 支持图片、纯文字笔记、TXT/CSV、PDF、Word、Excel、PPT 导入与分类管理，支持点击直接调用离线 OCR 识别其中的文字。

### 4. 🎵 零存储占用音乐播放器 & 硬件音效
- **零额外内存/存储占用**：本地音乐通过 Android SAF 持久化 URI **直接读取原路径播放**，不复制音频文件；导入新歌不打断当前播放。
- **后台丝滑不卡顿**：原生 Android `MusicService` 前台媒体服务硬件解码，切桌面/锁屏流畅播放、自动切歌并实时同步歌名与进度条。
- **多源在线搜歌**：聚合网易云公开接口、Apple 多区曲库与 Audius 免费曲库，在线流式直连播放（不落盘缓存），仅保留轻量搜索历史与收藏链接。
- **硬件 EQ 音效 & 白噪音**：支持原声/重低音/人声/助眠/大厅 5 种预设、低/中/高音 3 段均衡器、0.75x~1.5x 倍速、列表/单曲/随机循环，以及 4 种离线助眠白噪音与定时关闭。

### 5. 📈 A股专区与全球股市行情 + 每日消息汇总
- **每日自动更新**：GitHub Actions 每天北京时间 `08:30` 与 `22:30` 自动抓取 **🇨🇳 A股 6 大指数 + 港股/美股/欧亚 18 大股指 + 25 只龙头股** 与每日财经头条汇总。
- **全网任意搜股**：东方财富 + Yahoo Finance 双引擎实时检索全球任意 A股/港股/美股及概念板块（个股优先展示）。
- **可滑动交互走势图**：支持切换 `5日分时 / 1月 / 3月 / 1年`，手指左右滑动即可出现十字准星查看任意时刻精确价格与区间涨跌幅。

### 6. 🌐 词典级多语言翻译
- 接入 **有道词典 + FreeDictionary + Google + MyMemory**，支持 9 种语言互译（国内免 VPN 也可查词翻译）。
- 展示 **英/美音标、词性释义、常用短语、中英双语例句**。
- **例句单词双击查词**：双击（连点两下）例句中任意英文单词直接跳转查词翻译。
- **多模式朗读**：支持读原文、读译文、**🗣️ 中外双语连读**，并支持图片/文档 OCR 识别翻译。

### 7. 🎨 个性化外观设置
- 支持 **主题配色自定义**（预设 + 自由取色器）、**黑夜模式**（浅色 / 深色 / 跟随系统）、**毛玻璃拟态开关**、**字体风格与字号调节**。
